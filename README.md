# Прошу Слова ИКИТ 2026 — TOTALIZATOR

Новый отдельный static-site проект для GitHub Pages.

## Файлы

- `index.html` — публичная страница участника.
- `styles.css` — визуальный стиль.
- `app.js` — интерфейс и динамическое обновление.
- `public-api.js` — подключение к Google Apps Script.
- `assets/` — сюда можно положить официальный логотип ИКИТ в SVG.

GitHub:

Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)`.

## Логика

OPEN:
- пользователь видит текущие коэффициенты;
- можно создать заявку;
- заявка становится PENDING;
- коэффициенты меняются только после подтверждения наличных организатором.

LOCKED:
- новые заявки запрещены backend-ом;
- коэффициенты зафиксированы;
- участник видит finalK.

RESULT:
- результат объявлен организатором;
- участник видит финальный коэффициент.

## Визуальная система

Интерфейс построен на светлой системе из брендбука Молодёжного центра ИКИТ СФУ: Alice Blue, Lavender, Ink Black, мягкие лавандовые градиенты, крупные скруглённые карточки и декоративные звёзды.

В коде предусмотрены fallback-шрифты с приоритетом `Futura Now Headline` для заголовков и `Gravity Regular` для основного текста. Официальные файлы шрифтов в репозиторий не включаются автоматом.
